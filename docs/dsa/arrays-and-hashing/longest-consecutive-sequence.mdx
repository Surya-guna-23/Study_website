# Longest Consecutive Sequence

> **LeetCode 128** – [Longest Consecutive Sequence](https://leetcode.com/problems/longest-consecutive-sequence/) | **Striver (TUF)** – [Longest Consecutive Sequence Article](https://takeuforward.org/data-structure/longest-consecutive-sequence-in-an-array/)

## Problem Statement

Given an unsorted array of integers `nums`, return the **length of the longest consecutive elements sequence**.

You must write an algorithm that runs in $O(n)$ time.

### Examples

| # | Input | Output | Explanation |
|---|-------|--------|-------------|
| 1 | `nums = [100,4,200,1,3,2]` | `4` | The sequence `[1, 2, 3, 4]` has length `4`. |
| 2 | `nums = [0,3,7,2,5,8,4,6,0,1]` | `9` | The sequence `[0..8]` has length `9`. |

### Constraints

- `0 <= nums.length <= 10⁵`
- `-10⁹ <= nums[i] <= 10⁹`

---

## Solution

**Approach:** Put all numbers in a `HashSet` for $O(1)$ lookups. A number is the **start of a sequence** only if `num - 1` is **not** in the set. For every such start, walk forward (`num + 1`, `num + 2`, …) counting the length. Because each number is visited at most twice, the total work is linear.

- **Time Complexity:** $O(n)$ — each element is only extended from its sequence start.
- **Space Complexity:** $O(n)$ — the set stores all elements.

```java
class Solution {
    public int longestConsecutive(int[] nums) {
        if (nums.length == 0) return 0;

        HashSet<Integer> set = new HashSet<>();
        for (int num : nums) {
            set.add(num);
        }

        int longest = 0;

        for (int num : set) {
            // Only start counting from the beginning of a sequence
            if (!set.contains(num - 1)) {
                int current = num;
                int count = 1;

                while (set.contains(current + 1)) {
                    current++;
                    count++;
                }

                longest = Math.max(longest, count);
            }
        }

        return longest;
    }
}
```

Let's walk through **Example 1**: `nums = [100, 4, 200, 1, 3, 2]`

**Set:** `{100, 4, 200, 1, 3, 2}`

| `num` | `set.contains(num - 1)?` | Is sequence start? | Walk forward | `count` | `longest` |
|-------|---------------------------|--------------------|--------------|---------|-----------|
| 100 | `99` → No | ✅ | `101`? No | 1 | 1 |
| 4 | `3` → **Yes** | ❌ skip | — | — | 1 |
| 200 | `199` → No | ✅ | `201`? No | 1 | 1 |
| 1 | `0` → No | ✅ | `2,3,4` present, `5`? No | 4 | **4** |
| 3 | `2` → **Yes** | ❌ skip | — | — | 4 |
| 2 | `1` → **Yes** | ❌ skip | — | — | 4 |

Only `1` triggers a full walk (`1 → 2 → 3 → 4`), giving the longest run of `4`.

**Result:** `4` ✅

System.out.println(new Solution().longestConsecutive(new int[]{100, 4, 200, 1, 3, 2}));          // 4
