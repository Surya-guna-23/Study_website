# Product of Array Except Self

<Difficulty level="Medium" />

> **LeetCode 238** – [Product of Array Except Self](https://leetcode.com/problems/product-of-array-except-self/) | **Striver (TUF)** – [Product of Array Except Self Article](https://takeuforward.org/data-structure/product-of-array-except-itself/)

## Problem Statement

Given an integer array `nums`, return an array `answer` such that `answer[i]` is equal to the **product of all the elements of `nums` except `nums[i]`**.

The product of any prefix or suffix of `nums` is guaranteed to fit in a **32-bit integer**.

You must write an algorithm that runs in $O(n)$ time and **without using the division operation**.

### Examples

| # | Input | Output |
|---|-------|--------|
| 1 | `nums = [1,2,3,4]` | `[24,12,8,6]` |
| 2 | `nums = [-1,1,0,-3,3]` | `[0,0,9,0,0]` |

### Constraints

- `2 <= nums.length <= 10⁵`
- `-30 <= nums[i] <= 30`
- The product of any prefix or suffix of `nums` fits in a 32-bit integer.

---

## Solution

**Approach:** Build the answer in two passes without division:

1. **Prefix pass (left → right):** `answer[i]` holds the product of all elements *to the left* of `i`.
2. **Suffix pass (right → left):** multiply each `answer[i]` by a running `right` product of all elements *to the right* of `i`.

- **Time Complexity:** $O(n)$ — two linear passes.
- **Space Complexity:** $O(1)$ extra — output array aside, only a single `right` variable is used.

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] answer = new int[n];

        // Prefix products: answer[i] = product of everything to the left of i
        answer[0] = 1;
        for (int i = 1; i < n; i++) {
            answer[i] = answer[i - 1] * nums[i - 1];
        }

        // Suffix products: multiply by everything to the right of i
        int right = 1;
        for (int i = n - 1; i >= 0; i--) {
            answer[i] = answer[i] * right;
            right = right * nums[i];
        }

        return answer;
    }
}
```

Let's walk through **Example 1**: `nums = [1, 2, 3, 4]`

**Step 1 — Prefix pass (left products):**

| `i` | `nums[i-1]` | `answer[i] = answer[i-1] * nums[i-1]` | `answer` |
|-----|-------------|----------------------------------------|----------|
| 0 | — | `1` (seed) | `[1, _, _, _]` |
| 1 | 1 | `1 * 1 = 1` | `[1, 1, _, _]` |
| 2 | 2 | `1 * 2 = 2` | `[1, 1, 2, _]` |
| 3 | 3 | `2 * 3 = 6` | `[1, 1, 2, 6]` |

**Step 2 — Suffix pass (right products), `right` starts at `1`:**

| `i` | `answer[i] * right` | new `answer[i]` | `right = right * nums[i]` |
|-----|----------------------|------------------|----------------------------|
| 3 | `6 * 1` | `6` | `1 * 4 = 4` |
| 2 | `2 * 4` | `8` | `4 * 3 = 12` |
| 1 | `1 * 12` | `12` | `12 * 2 = 24` |
| 0 | `1 * 24` | `24` | `24 * 1 = 24` |

**Result:** `[24, 12, 8, 6]` ✅
