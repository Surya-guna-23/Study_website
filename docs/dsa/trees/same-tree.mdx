# Same Tree

<Difficulty level="Easy" />

> **LeetCode 100** – [Same Tree](https://leetcode.com/problems/same-tree/) | **Striver (TUF)** – [Check if Two Trees are Identical](https://takeuforward.org/data-structure/check-if-two-trees-are-identical/)

## Problem Statement

Given the roots of two binary trees `p` and `q`, return `true` if they are **structurally identical** and the nodes have the **same values**.

### Examples

| # | Input | Output |
|---|-------|--------|
| 1 | `p = [1,2,3]`, `q = [1,2,3]` | `true` |
| 2 | `p = [1,2]`, `q = [1,null,2]` | `false` |
| 3 | `p = [1,2,1]`, `q = [1,1,2]` | `false` |

### Constraints

- The number of nodes in each tree is in the range `[0, 100]`.
- `-10⁴ <= Node.val <= 10⁴`

---

## Solution

**Approach:** Walk both trees in lock-step. Three checks at each pair of nodes:

1. Both `null` → identical so far, return `true`.
2. Exactly one `null`, or values differ → return `false`.
3. Otherwise recurse on both left pairs and both right pairs.

- **Time Complexity:** $O(n)$ — `n` is the size of the smaller tree.
- **Space Complexity:** $O(h)$ — recursion stack.

<Tabs groupId="lang">
<TabItem value="js" label="JavaScript">

```js
/**
 * @param {TreeNode} p
 * @param {TreeNode} q
 * @return {boolean}
 */
var isSameTree = function(p, q) {
    if (p === null && q === null) return true;
    if (p === null || q === null) return false;
    if (p.val !== q.val) return false;
    return isSameTree(p.left, q.left) && isSameTree(p.right, q.right);
};
```

</TabItem>
<TabItem value="java" label="Java">

```java
class Solution {
    public boolean isSameTree(TreeNode p, TreeNode q) {
        if (p == null && q == null) return true;
        if (p == null || q == null) return false;
        if (p.val != q.val) return false;
        return isSameTree(p.left, q.left) && isSameTree(p.right, q.right);
    }
}
```
