# K Closest Points to Origin

<Difficulty level="Medium" />

> **LeetCode 973** – [K Closest Points to Origin](https://leetcode.com/problems/k-closest-points-to-origin/)

## Problem Statement

Given an array of `points` where `points[i] = [xᵢ, yᵢ]` and an integer `k`, return the `k` closest points to the origin `(0, 0)`.

The distance is the Euclidean distance `sqrt(x² + y²)`. The answer may be returned in any order.

### Examples

| # | Input | Output |
|---|-------|--------|
| 1 | `points = [[1,3],[-2,2]]`, `k = 1` | `[[-2,2]]` |
| 2 | `points = [[3,3],[5,-1],[-2,4]]`, `k = 2` | `[[3,3],[-2,4]]` |

### Constraints

- `1 <= k <= points.length <= 10⁴`
- `-10⁴ <= xᵢ, yᵢ <= 10⁴`

---

## Approaches (Striver / TUF progression)

| # | Approach | Time | Space |
|---|----------|------|-------|
| 1 | Sort all points by distance, take the first `k` | $O(n \log n)$ | $O(n)$ |
| 2 | **Max-heap of size k** | $O(n \log k)$ | $O(k)$ |
| 3 | Quickselect on distance | $O(n)$ average | $O(1)$ |

Sorting is the simplest and is usually fast enough. The heap wins when `k ≪ n` (or the points stream in), and quickselect is asymptotically best but rarely needed at these constraints.

## Solution

**Approach:** Two useful observations:

1. We can compare **squared** distances `x² + y²` and skip the square root entirely — it is monotonic, so the ordering is identical (and we avoid floating-point error).
2. Keep a **max-heap of size `k`** keyed by squared distance. Whenever it overflows, evict the *farthest* point. What remains are the `k` closest.

- **Time Complexity:** $O(n \log k)$ — better than sorting everything when `k ≪ n`.
- **Space Complexity:** $O(k)$.

<TabItem value="js" label="JavaScript">

```js
/**
 * @param {number[][]} points
 * @param {number} k
 * @return {number[][]}
 */
var kClosest = function(points, k) {
    // Simple and clear: sort by squared distance.  O(n log n)
    return [...points]
        .sort((a, b) => (a[0] ** 2 + a[1] ** 2) - (b[0] ** 2 + b[1] ** 2))
        .slice(0, k);
};
```

Heap version — `O(n log k)`, preferable when `k` is much smaller than `n`:

```js
var kClosestHeap = function(points, k) {
    const heap = []; // max-heap of [dist, point] via manual sift
    const dist = (p) => p[0] ** 2 + p[1] ** 2;
    const swap = (i, j) => { [heap[i], heap[j]] = [heap[j], heap[i]]; };

    const up = (i) => {
        while (i > 0) {
            const p = (i - 1) >> 1;
            if (dist(heap[p]) >= dist(heap[i])) break;
            swap(p, i); i = p;
        }
    };
    const down = (i) => {
        for (;;) {
            const l = 2 * i + 1, r = l + 1;
            let big = i;
            if (l < heap.length && dist(heap[l]) > dist(heap[big])) big = l;
            if (r < heap.length && dist(heap[r]) > dist(heap[big])) big = r;
            if (big === i) break;
            swap(big, i); i = big;
        }
    };

    for (const p of points) {
        heap.push(p); up(heap.length - 1);
        if (heap.length > k) { heap[0] = heap.pop(); down(0); }
    }
    return heap;
};
```

<TabItem value="java" label="Java">

```java
import java.util.PriorityQueue;

class Solution {
    public int[][] kClosest(int[][] points, int k) {
        // max-heap by squared distance
        PriorityQueue<int[]> pq = new PriorityQueue<>(
            (a, b) -> (b[0] * b[0] + b[1] * b[1]) - (a[0] * a[0] + a[1] * a[1])
        );
        for (int[] p : points) {
            pq.offer(p);
            if (pq.size() > k) pq.poll();
        }
        int[][] res = new int[k][2];
        for (int i = 0; i < k; i++) res[i] = pq.poll();
        return res;
    }
}
```
