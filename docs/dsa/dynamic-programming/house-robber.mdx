# House Robber

<Difficulty level="Medium" />

> **LeetCode 198** – [House Robber](https://leetcode.com/problems/house-robber/) | **Striver (TUF)** – [Maximum Sum of Non-Adjacent Elements (DP-5)](https://takeuforward.org/data-structure/maximum-sum-of-non-adjacent-elements-dp-5/)

## Problem Statement

You are a robber planning to rob houses along a street. Each house has a certain amount of money stashed. **Adjacent houses have security systems connected** — robbing two adjacent houses on the same night triggers the alarm.

Given an integer array `nums` representing the money in each house, return the **maximum amount** you can rob tonight without alerting the police.

### Examples

| # | Input | Output | Explanation |
|---|-------|--------|-------------|
| 1 | `nums = [1,2,3,1]` | `4` | Rob house 0 (1) and house 2 (3) |
| 2 | `nums = [2,7,9,3,1]` | `12` | Rob houses 0, 2, 4 → 2 + 9 + 1 |

### Constraints

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 400`

---

## Approaches (Striver / TUF progression)

| # | Approach | Time | Space |
|---|----------|------|-------|
| 1 | Recursion (pick / not-pick) | $O(2^n)$ | $O(n)$ |
| 2 | Memoization | $O(n)$ | $O(n) + O(n)$ |
| 3 | Tabulation | $O(n)$ | $O(n)$ |
| 4 | **Space optimised** | $O(n)$ | $O(1)$ |

### Step 1 — Express in terms of index

At house `i` we make a binary choice:

- **Pick** it → we gain `nums[i]` but must jump to `i-2`.
- **Skip** it → we gain nothing and move to `i-1`.

$$
f(i) = \max(nums[i] + f(i-2),\; f(i-1))
$$

### Step 2 — Base cases

`f(0) = nums[0]`. For any negative index, return `0` (no houses left, no money).

:::tip Common mistake
A greedy "take every alternate house" strategy is **wrong**. For `[2,1,1,9]`, alternating gives `2 + 1 = 3`, but the best is `2 + 9 = 11`. The DP compares both options at every index instead of assuming one.
:::

### Step 3 — Space optimisation

`f(i)` only ever reads `f(i-1)` and `f(i-2)`, so two variables replace the entire array.

## Solution

<Tabs groupId="lang">
<TabItem value="js" label="JavaScript">

**Approach 1 — Recursion:**

```js
const solve = (nums, i) => {
    if (i < 0) return 0;
    if (i === 0) return nums[0];
    const pick = nums[i] + solve(nums, i - 2);
    const skip = solve(nums, i - 1);
    return Math.max(pick, skip);
};
var robRec = (nums) => solve(nums, nums.length - 1);
```

**Approach 2 — Memoization:**

```js
var robMemo = function(nums) {
    const dp = new Array(nums.length).fill(-1);
    const solve = (i) => {
        if (i < 0) return 0;
        if (i === 0) return nums[0];
        if (dp[i] !== -1) return dp[i];
        return dp[i] = Math.max(nums[i] + solve(i - 2), solve(i - 1));
    };
    return solve(nums.length - 1);
};
```

**Approach 3 — Tabulation:**

```js
var robTab = function(nums) {
    const n = nums.length;
    const dp = new Array(n).fill(0);
    dp[0] = nums[0];
    for (let i = 1; i < n; i++) {
        const pick = nums[i] + (i > 1 ? dp[i - 2] : 0);
        const skip = dp[i - 1];
        dp[i] = Math.max(pick, skip);
    }
    return dp[n - 1];
};
```

**Approach 4 — Space optimised (final answer):**

```js
/**
 * @param {number[]} nums
 * @return {number}
 */
var rob = function(nums) {
    let prev2 = 0;          // best up to i-2
    let prev1 = nums[0];    // best up to i-1
    for (let i = 1; i < nums.length; i++) {
        const pick = nums[i] + prev2;
        const skip = prev1;
        const cur = Math.max(pick, skip);
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
};
```

<TabItem value="java" label="Java">

```java
class Solution {
    // Space optimised — O(n) time, O(1) space
    public int rob(int[] nums) {
        int prev2 = 0, prev1 = nums[0];
        for (int i = 1; i < nums.length; i++) {
            int pick = nums[i] + prev2;
            int skip = prev1;
            int cur = Math.max(pick, skip);
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }

    // Tabulation — O(n) time, O(n) space
    public int robTab(int[] nums) {
        int n = nums.length;
        int[] dp = new int[n];
        dp[0] = nums[0];
        for (int i = 1; i < n; i++) {
            int pick = nums[i] + (i > 1 ? dp[i - 2] : 0);
            dp[i] = Math.max(pick, dp[i - 1]);
        }
        return dp[n - 1];
    }
}
```
