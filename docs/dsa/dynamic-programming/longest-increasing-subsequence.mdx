# Longest Increasing Subsequence

<Difficulty level="Medium" />

> **LeetCode 300** – [Longest Increasing Subsequence](https://leetcode.com/problems/longest-increasing-subsequence/) | **Striver (TUF)** – [Longest Increasing Subsequence (DP-41)](https://takeuforward.org/data-structure/longest-increasing-subsequence-dp-41/)

## Problem Statement

Given an integer array `nums`, return the length of the **longest strictly increasing subsequence**.

A subsequence is derived by deleting some or no elements **without changing the order** of the remaining ones.

### Examples

| # | Input | Output | LIS |
|---|-------|--------|-----|
| 1 | `nums = [10,9,2,5,3,7,101,18]` | `4` | `[2,3,7,101]` |
| 2 | `nums = [0,1,0,3,2,3]` | `4` | `[0,1,2,3]` |
| 3 | `nums = [7,7,7,7,7]` | `1` | `[7]` |

### Constraints

- `1 <= nums.length <= 2500`
- `-10⁴ <= nums[i] <= 10⁴`

---

## Approaches (Striver / TUF progression)

| # | Approach | Time | Space |
|---|----------|------|-------|
| 1 | Recursion (take / not-take) | $O(2^n)$ | $O(n)$ |
| 2 | Memoization (index, prevIndex) | $O(n^2)$ | $O(n^2)$ |
| 3 | **Tabulation (1-D dp)** | $O(n^2)$ | $O(n)$ |
| 4 | Binary search / patience sorting | $O(n \log n)$ | $O(n)$ |

### Step 1 — The 1-D formulation

Define `dp[i]` = **length of the LIS that ends exactly at index `i`**.

Anchoring the subsequence at `i` is the key idea: to extend it we only need some earlier index `j` with a smaller value.

$$
dp[i] = 1 + \max \big( dp[j] \big)
$$

…taken over all `j < i` where `nums[j] < nums[i]`.

If no such `j` exists, `dp[i] = 1` (the element alone).

### Step 2 — The answer

The LIS can end anywhere, so the answer is `max(dp)` — **not** `dp[n-1]`. This is the single most common bug in this problem.

### Step 3 — The `O(n log n)` optimisation

Maintain a `tails` array where `tails[k]` is the **smallest possible tail value** of an increasing subsequence of length `k+1`. For each number, binary search for the first tail `>=` it and overwrite it; if none exists, append. The length of `tails` is the LIS length.

:::warning
`tails` is **not** a valid LIS itself — only its *length* is meaningful.
:::

## Solution

<Tabs groupId="lang">
<TabItem value="js" label="JavaScript">

**Approach 3 — Tabulation, `O(n²)`:**

```js
/**
 * @param {number[]} nums
 * @return {number}
 */
var lengthOfLIS = function(nums) {
    const n = nums.length;
    const dp = new Array(n).fill(1);   // every element alone is an LIS of 1
    let best = 1;

    for (let i = 1; i < n; i++) {
        for (let j = 0; j < i; j++) {
            if (nums[j] < nums[i]) {
                dp[i] = Math.max(dp[i], 1 + dp[j]);
            }
        }
        best = Math.max(best, dp[i]);
    }
    return best;
};
```

**Approach 4 — Binary search, `O(n log n)`:**

```js
var lengthOfLISFast = function(nums) {
    const tails = [];
    for (const x of nums) {
        // first index with tails[idx] >= x
        let lo = 0, hi = tails.length;
        while (lo < hi) {
            const mid = (lo + hi) >> 1;
            if (tails[mid] < x) lo = mid + 1;
            else hi = mid;
        }
        if (lo === tails.length) tails.push(x);
        else tails[lo] = x;
    }
    return tails.length;
};
```

<TabItem value="java" label="Java">

```java
import java.util.Arrays;

class Solution {
    // Tabulation — O(n^2)
    public int lengthOfLIS(int[] nums) {
        int n = nums.length;
        int[] dp = new int[n];
        Arrays.fill(dp, 1);
        int best = 1;
        for (int i = 1; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (nums[j] < nums[i]) dp[i] = Math.max(dp[i], 1 + dp[j]);
            }
            best = Math.max(best, dp[i]);
        }
        return best;
    }

    // Binary search — O(n log n)
    public int lengthOfLISFast(int[] nums) {
        int[] tails = new int[nums.length];
        int size = 0;
        for (int x : nums) {
            int idx = Arrays.binarySearch(tails, 0, size, x);
            if (idx < 0) idx = -(idx + 1);
            tails[idx] = x;
            if (idx == size) size++;
        }
        return size;
    }
}
```
