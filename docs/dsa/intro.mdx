# Data Structures & Algorithms

Welcome to the DSA section! Each problem here follows the same structure so it's easy to study:

- **Problem statement** with examples and constraints
- **Solution** in JavaScript and Java with time/space complexity
- **Visual dry run** — a step-by-step diagram (click to zoom) plus a walkthrough table
- **Test cases** you can run

## Patterns

- **Arrays & Hashing** — Contains Duplicate, Valid Anagram, Two Sum, Group Anagrams, Top K Frequent, Product of Array Except Self, Longest Consecutive Sequence
- **Two Pointers** — Valid Palindrome, Two Sum II, 3Sum, Container With Most Water, Trapping Rain Water
- **Sliding Window** — Best Time to Buy/Sell Stock, Longest Substring Without Repeating Characters, Longest Repeating Character Replacement
- **Binary Search** — Binary Search, Koko Eating Bananas, Search in Rotated Sorted Array, Find Minimum in Rotated Sorted Array, Median of Two Sorted Arrays
- **Linked List** — Reverse, Merge, Cycle Detection, Reorder, K-Group, and more
- **Stack** — Valid Parentheses, Min Stack, Evaluate Reverse Polish Notation, Daily Temperatures, Generate Parentheses
- **Trees** — Invert Binary Tree, Maximum Depth, Same Tree, Level Order Traversal, LCA of a BST, Validate BST
- **Heap / Priority Queue** — Last Stone Weight, Kth Largest in a Stream, K Closest Points to Origin, Kth Largest in an Array
- **Backtracking** — Subsets, Combination Sum, Permutations, Word Search
- **1-D Dynamic Programming** — Climbing Stairs, House Robber, Coin Change, Longest Increasing Subsequence

> Problems are curated from **LeetCode** and **Striver's (TakeUForward) SDE sheet**.

Most problems follow the Striver/TUF progression — **brute force → better → optimal** — so you can see *why* the optimal solution looks the way it does, not just what it is.
