# Subsets

<Difficulty level="Medium" />

> **LeetCode 78** – [Subsets](https://leetcode.com/problems/subsets/) | **Striver (TUF)** – [Power Set: Print All Subsequences](https://takeuforward.org/data-structure/power-set-print-all-the-possible-subsequences-of-the-string/)

## Problem Statement

Given an integer array `nums` of **unique** elements, return all possible subsets (the **power set**).

The solution set must not contain duplicate subsets. Return the answer in any order.

### Examples

| # | Input | Output |
|---|-------|--------|
| 1 | `nums = [1,2,3]` | `[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]` |
| 2 | `nums = [0]` | `[[],[0]]` |

### Constraints

- `1 <= nums.length <= 10`
- `-10 <= nums[i] <= 10`
- All numbers are unique.

---

## Approaches (Striver / TUF progression)

| # | Approach | Time | Space |
|---|----------|------|-------|
| 1 | **Recursion: pick / not-pick** | $O(n \cdot 2^n)$ | $O(n)$ |
| 2 | Iterative — grow the result set | $O(n \cdot 2^n)$ | $O(1)$ extra |
| 3 | Bitmask enumeration | $O(n \cdot 2^n)$ | $O(1)$ extra |

All three are optimal in time — you cannot beat `2ⁿ` when you must *print* `2ⁿ` subsets. They differ only in style.

### Approach 3 — Bitmask

Every integer from `0` to `2ⁿ - 1` encodes one subset: bit `i` set means “include `nums[i]`”. Elegant and loop-only, but limited to `n ≤ 31`.

```js
var subsetsBitmask = function(nums) {
    const n = nums.length, res = [];
    for (let mask = 0; mask < (1 << n); mask++) {
        const sub = [];
        for (let i = 0; i < n; i++) {
            if (mask & (1 << i)) sub.push(nums[i]);
        }
        res.push(sub);
    }
    return res;
};
```

## Solution

**Approach (include / exclude):** For every element there are exactly two choices — put it in the current subset or leave it out. Recursing on those two branches for all `n` elements enumerates all `2ⁿ` subsets. When the index reaches the end of the array, the current path is a complete subset.

The key backtracking move is the `pop()` after the "include" branch: it undoes the choice so the "exclude" branch starts from a clean state.

- **Time Complexity:** $O(n \cdot 2^n)$ — `2ⁿ` subsets, each costing `O(n)` to copy.
- **Space Complexity:** $O(n)$ — recursion depth and the current path (excluding output).

<TabItem value="js" label="JavaScript">

```js
/**
 * @param {number[]} nums
 * @return {number[][]}
 */
var subsets = function(nums) {
    const res = [];
    const path = [];

    const backtrack = (i) => {
        if (i === nums.length) {
            res.push([...path]);   // copy — path keeps mutating
            return;
        }
        // choice 1: include nums[i]
        path.push(nums[i]);
        backtrack(i + 1);
        path.pop();                // undo the choice

        // choice 2: exclude nums[i]
        backtrack(i + 1);
    };

    backtrack(0);
    return res;
};
```

Iterative alternative — grow the result set one element at a time:

```js
var subsetsIterative = function(nums) {
    let res = [[]];
    for (const n of nums) {
        res = res.concat(res.map((sub) => [...sub, n]));
    }
    return res;
};
```

<TabItem value="java" label="Java">

```java
import java.util.*;

class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        backtrack(nums, 0, new ArrayList<>(), res);
        return res;
    }

    private void backtrack(int[] nums, int i, List<Integer> path, List<List<Integer>> res) {
        if (i == nums.length) {
            res.add(new ArrayList<>(path));
            return;
        }
        path.add(nums[i]);
        backtrack(nums, i + 1, path, res);
        path.remove(path.size() - 1);

        backtrack(nums, i + 1, path, res);
    }
}
```
