# Source library

Use the local guide to learn and rehearse; use the linked material to inspect the original context. Topic titles, routes, source URLs, and per-topic review notes below come directly from the **same four JSON datasets as the catalog**. They are not a second hand-maintained bibliography.

See the supplementary [PDF access audit (2026-11-01)](source-access.md) for bounded public-download, page-count, and text-extraction results. Access or extraction does **not** establish semantic review or audit the guides against every PDF; the detailed review labels below remain unchanged.

## What has actually been reviewed?

- **PDF text reviewed:** Parking Lot, Strategy, and all five SOLID extracted texts (single responsibility, open/closed, Liskov substitution, interface segregation, dependency inversion). This is text review, not visual verification of embedded UML images, page layouts, or videos.
- **Other PDFs:** downloaded and extracted in the access audit, but most have only opening-sample inspection. MVC, Adapter, and Proxy additionally received full extracted-text reading with limited observations in that audit. This does not mean the teaching guides have been checked against every PDF. Listing a collection does not mean every file in it has been read.
- **Java:** review claims apply only to the files identified in each topic's note and guide. LLD repository details are pinned to **5afdde64cd138ed7a8e273870598b41d63914e91**; a directory link alone is not evidence that every implementation was reviewed.
- **Separate HashMap repository:** the supplied source was accessible and read at **86f5cba306799544cb10f9b57adf00dedf16253f**. The LLD repository commit above does not apply to this repository. Inventory-management source remains unverified as noted in its metadata.
- **Original interview models:** site diagrams, refactors, scripts, and Java teaching examples are not transcriptions or claims of production readiness. Static source review is not execution or a correctness certification.
- **[SOURCE UNVERIFIED]:** where used, a URL is known but its implementation behavior has not been established. A reachable landing page alone does not count as code review.

Public access does not grant permission to republish an entire external PDF or codebase. This library links the originals and limits the guides to original explanations, examples, and scoped observations.
